Coloque aqui as logos das empresas, com EXATAMENTE estes nomes:

  ttt.png        — TT&T
  locarmais.png  — Locarmais
  oderco.png     — Grupo Oderço

Formatos aceitos: .png (ou .svg/.webp, mas aí ajuste o caminho em data.jsx → COMPANIES[].logo).
Fundo transparente de preferência. Se um arquivo faltar, o site mostra o placeholder [ logo ] no lugar (não quebra).

Depois de salvar: npm run build && git add/commit/push.
