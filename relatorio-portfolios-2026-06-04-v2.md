## Insights gerais do dia

**1. O eixo "IA como problema de design" amadureceu — e agora tem um sub-perfil claro: o pesquisador de interfaces.** A leva de hoje traz três pessoas que não desenham telas de IA, mas *inventam a linguagem de interação* dela: Maggie Appleton (GitHub Next, ex-lead da Elicit), Amelia Wattenberger (Principal na GitHub Next) e Linus Lee (advisor na Thrive, ex-Notion). Os ensaios deles — "Chatbots não são o futuro", "Nossas interfaces perderam os sentidos", "Generative interfaces beyond chat" — são, na prática, a fundação teórica que falta na maioria dos cases de IA do mercado. Para você, que quer um case autoral de IA, ler esses três é o atalho para sair do óbvio (mais um chat) e desenhar algo defensável.

**2. "Portfólio é o próprio produto" virou padrão no topo — e isso ataca direto seu ponto fraco de UI.** Metade da lista prova senioridade pela qualidade do site em si: Lynn Fisher reconstrói o portfólio do zero todo ano só para aprender CSS novo, Cassie Evans transforma SVG/animação em vocabulário próprio, Josh Comeau ensina micro-interação com guias interativos, Ryo Lu (Cursor) faz uma homenagem ao Mac OS X em JS. Não é exibicionismo gratuito: é a prova de UI de quem domina estado, timing e detalhe. Estude esses quatro como **aula de acabamento**, não como modelo narrativo.

**3. O "design engineer" agora também é "AI-native designer": quem desenha, constrói E usa IA para shipar.** Ryo Lu lidera design na Cursor e monta produtos com agentes; Paul Farino (Staff na Meta) mantém uma seção de "Experiments" cheia de ferramentas internas que ele mesmo codou (alinhador de cores, visualizador de IA/ERD, plugin de Figma→Slack). A mensagem para você é direta: um único micro-experimento funcional, feito com v0/Cursor/Claude, comunica senioridade mais rápido que três telas estáticas.

**4. Existe um modelo "anti-chat" de portfólio que já é tendência — e o cjdowner.com é o exemplo perfeito.** Christopher Downer (ex-Sketch) transformou o portfólio numa interface de chat ("ChatCJD — what can I help with?"). É arriscado e divisivo, mas mostra a fronteira: usar a própria estética de IA como meta-statement. Vale conhecer para entender para onde a expectativa visual está indo — não necessariamente para copiar.

**5. Para CONTAR sua história, o modelo seguro continua sendo o case end-to-end com impacto — e hoje tem dois bons espelhos.** Rosie Zhang (Sr. PD, fintech/e-commerce) estrutura cada projeto como problema → alinhamento de times → design system → impacto; Krystal Higgins (ex-Google, autora de *Better Onboarding*) prova senioridade via estratégia, sistemas e um tema de especialista (onboarding). Como sua gestão hoje **não** prioriza pesquisa formal, repare especialmente na Rosie: ela demonstra rigor de UX (testes iterativos, alinhamento cross-funcional) sem depender de relatórios acadêmicos de pesquisa.

### Como aplicar no seu portfólio (resumo acionável)
1. **Defina seu tema-assinatura** (à la Krystal Higgins) e estruture os cases no modelo problema → alinhamento → solução → **impacto** (à la Rosie Zhang). Esse é o esqueleto seguro para vaga de UX Sênior.
2. **Crie 1 case autoral de IA com fundamento** — antes de desenhar a tela, leia Maggie Appleton, Wattenberger e Linus Lee para definir *o problema de interação da IA* (não só "mais um chat").
3. **Shipe 1 micro-experimento funcional** no espírito da seção "Experiments" do Paul Farino (uma ferramentinha buildável com v0/Cursor/Claude). Iniciativa concreta > telas estáticas.
4. **Ataque seu ponto fraco de UI** com Josh Comeau (micro-interação e CSS) e Cassie Evans (motion/SVG) — é estudo prático e direto.
5. **Trate seu site como produto, MAS com a lição técnica do Jesse/Rosie:** não dependa 100% de JS — cuide de performance, SEO e acessibilidade. Beleza sem render = trabalho invisível para recrutador e ATS.
